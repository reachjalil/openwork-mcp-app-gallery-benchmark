Independent hosted adaptation

MCP Apps example gallery

This gallery hosts six official MCP Apps examples as distinct remote Streamable HTTP servers. It is not an official Model Context Protocol service.

How to try in OpenWork

  1. Copy one MCP URL below.
  2. Add it as a remote Streamable HTTP MCP server in an MCP Apps-compatible host.
  3. Send the suggested prompt.
  4. If the host has no App UI, the ordinary text or structured tool result still works.
